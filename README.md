# CCFOLIA ステータス変更

拡張機能アイコンから専用の制御ウィンドウを開き、開いているCCFOLIAルームの盤面キャラクターを上から順に操作します。「キャラ情報を取得」でキャラクター名を一覧表示し、複数選択または一人だけ選択するモードで対象を指定できます。対象にできるステータスはHP、MP、SANです。各ステータスを指定量だけ増減するか、入力した値に設定できます。値は1〜20のボタンでも選択できます。

## 操作仕様

- キャラクターごとに対象ステータスの表示行をクリックして編集画面を開く。
- キャラ情報取得では各HP行を開き、編集画面とキャラクター個別のDOMから名前を読み取る。名前を取得できない場合は一覧順の仮名を表示し、同名の場合は一覧順の番号を付けて区別する。
- キャラクター一覧で各キャラに1〜16の番号を割り当て、チャットコマンド欄に`1s10`、`1,2m-5`、`3h-2`の形式で入力して複数キャラのステータスを変更できる（s=SAN、m=MP、h=HP）。各項目とも値を続けて書くと増加（`1s10`、`1m10`、`1h10`）、空白を入れると減少（`1s 10`、`1m 10`、`1h 10`）。1行につき1コマンドで、Enterで実行、Shift+Enterで改行する。明示的な`+`・`-`も指定できる。
- 同じ番号付きコマンドはCCFOLIAルームのメッセージ入力欄でも使える。コマンドだけの入力をEnterまたは送信ボタンで実行し、通常のチャットメッセージはそのまま送信する。番号の割り当てを変更した場合は拡張機能の制御ウィンドウを開いて同期する。
- 増減では対応するCCFOLIAのボタンを指定回数押す。
- 増加と指定値への設定では表示中の現在値・最大値を読み取り、最大値を超えないようにする。指定値が最大値より大きい場合は最大値までに制限する。
- 減少と指定値への設定では現在値を0未満にしない。減少量が現在値を超える場合は0までに制限する。
- 指定値への設定では目標値との差分に応じて増減ボタンを押す。現在値・最大値を読み取れない場合は操作を停止する。
- 各キャラクターの処理後、CCFOLIA画面の編集画面外を一度クリックして閉じ、変更反映を待ってから次へ進む。最後のキャラクターも編集画面を閉じ、反映を待ってから終了する。
- HP、MP、SAN以外のステータスは操作しない。

## 読み込み

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. CCFOLIAのルームを開く、または再読み込みする
5. Chrome右上の拡張機能アイコンから本拡張機能をクリックし、「キャラ情報を取得」を押して対象キャラクターを選ぶ
6. キャラクターごとに必要な番号を割り当て、制御ウィンドウまたはCCFOLIAルームのメッセージ入力欄でコマンドを実行する

## 注意

- CCFOLIAのDOM変更で動かなくなる可能性があります。表示行やボタンが見つからない場合は安全のため停止します。
- SANの増加・減少ボタンは `aria-label="SANを増やす"` と `aria-label="SANを減らす"` を使います。
- 指定値への設定では表示された数値から現在値を読み取ります。値を読み取れない場合は変更しません。
- 実行前に対象・操作・値を確認してください。送信済みコマンドをこの拡張機能から取り消す機能はありません。
- 非公式の拡張機能です。CCFOLIAの利用規約・卓の合意に従って使用してください。
