# CCFOLIA 拡張ルームチャット

CCFOLIAのルームチャットを、使いやすく拡張するブラウザー拡張機能です。
チャットの送受信や技能・ダイス入力を、ルーム画面上の拡張チャットから操作できます。

## 拡張チャットでできること

- 既存のルームチャットと拡張チャットを切り替え。拡張チャットはルーム画面に重ねて表示します。
- ルームごとに分離したチャットログの確認、タブ切り替え、発言キャラクターの選択
- 技能パレットから技能を選んで入力
- ダイスやSANチェックの式をボタンで入力
- HP・MP・SANの変更、よく使う文章の登録
- 未読メッセージの通知やチャット表示のカスタマイズ

## インストール

1. GitHubの **Code → Download ZIP** からダウンロードし、ZIPファイルを展開します。
2. Chromeで `chrome://extensions` を開きます。Edgeの場合は `edge://extensions` を開きます。
3. **デベロッパーモード**をONにします。
4. **パッケージ化されていない拡張機能を読み込む**を押し、展開したフォルダーを選びます。
5. CCFOLIAのルームを開きます。すでに開いている場合は、ページを再読み込みします。

## 使いはじめる

1. CCFOLIAのルーム画面上端にマウスを近づけます。
2. 表示された切り替えボタンを押し、**拡張チャット**を選びます。
3. 拡張チャットの歯車ボタンから設定を開き、**更新**を押します。
4. キャラクター一覧に番号を付けます。技能やキャラクター情報が読み込まれたら準備完了です。

## チャットを使う

入力欄に文章を書き、Enterまたは**送信**を押します。送信先はチャットタブのボタンで選べます。

- **技能**: 発言キャラクターの横にあるリストボタンから選びます。
- 入力中に技能候補が表示されたら、Tabまたは矢印キーで選び、Enterで入力欄に入れます。候補の選択だけでは送信されません。
- **ダイス・SANチェック**: ボタンを押して式を入力し、内容を確認してから送信します。
- **関数（よく使う文章）**: 設定すると、個別の「ボタン：表示」をONにしたものがチャット欄に表示されます。設定欄の「大きくする」で関数本文の入力欄を広げられ、選択した表示モードは保存されます。`;`で複数の発言や操作を区切り、`#delay 0.8;`を挟むと次の操作まで0.8秒待ちます。`/s2;`のように`/s`に数字を続けると、一致するシーンへ切り替えます。`/c キャラクター名;`、`/t タブ名;`、`/f 関数名;`で、キャラクター・タブの切り替えや別関数の呼び出しができます。それ以外の`/`から始まるコマンドは、内容を変えずそのままCCFOLIAへ送信します。`int a = 1d8; 1s-[a];`のように書くと、ダイス結果を関数内だけの整数変数`a`に代入し、`[a]`をその値に置き換えて後続のコマンドで使えます。`3:こんにちは;`なら「こんにちは」を3回送ります。この回数指定は通常の入力欄でも使えます（最大1000回）。**if構文**も使えます: `if (a > 3) { 成功; } else { 失敗; }`のように、C言語と同じ形で条件に合う側の文だけを送ります（条件に変数`a`を名前だけで書けます。`!=`,`&&`,`||`,`!`と、四則演算・`()`も使用可。elseに`else if (...)`を続けられます）。空もとに送るなら `{ }` とだけ書いてください。

## 入力欄のショートカット

入力欄で `/` を押すとコマンド候補が表示されます。Tabまたは矢印キーで選び、Enterで決定します。コマンド名を直接入力した場合も、続けて候補を選べます。候補の選択だけではメッセージは送信されません。`/l`と入力してEnterを押すと、画面の**更新**ボタンと同じ処理を行います。

| 入力 | 選べるもの | Enterを押すと |
| --- | --- | --- |
| `/g` | 技能 | 技能の式を入力欄に入れます |
| `/c` | キャラクター | 発言キャラクターを切り替えます |
| `/t` | チャットタブ | タブを切り替え、以後の送信先にします |
| `/grep` | 検索語 | 検索語をログ検索欄に入れて、検索欄へ移動します（`/gr` でも同じ） |
| `/f` | 登録した関数 | 登録内容を入力欄に入れます |
| `/vc` | マイキャラクター一覧のキャラクター | 選んだキャラを盤面に追加します（すでに盤面にいるなら、選択で盤面から外します） |
| `/vp` | スクリーンパネル一覧のパネル | 選んだパネルを表示します（すでに表示中なら、選択で非表示にします） |
| `/n` | 能力値（STR、CON、POW、DEX、APP、SIZ、INT、EDU） | 選んだ能力値名を入力欄に入れます |
| `/l` | — | キャラクター・技能パレット・シーン・チャットログを更新します |

`/g`の技能候補を使うには、先に**更新**でチャットパレットを読み込んでください。`/f`は設定で関数を登録すると使えます（以前の`/a`も引き続き使えます）。

`/vc`は、マイキャラクター一覧（顔アイコンのボタン）からキャラクターを読み込んで出します。`/vp`は、スクリーンパネル一覧（レイヤーアイコンのボタン）からパネルを読み込んで出します。候補の行には現在の状態を示す**1ボタン**が付き（**表示中は緑、非表示は赤**）、行を選んでクリック（またはCtrl+Enter）すると**変更予定に入り**、切り替え後の状態（→表示／→非表示）がボタンに出ます。候補の下の**「確定」ボタン（またはEnter）で、予定した行をまとめて切り替えます**（盤面にいないキャラなら**盤面に追加**され、盤面にいるキャラは**盤面から外れて隠れます**。非表示のパネルは**表示**し、表示中のパネルは**非表示**になります）。予定の付け直しはもう一度押すだけ、Escで予定をすべて解除します。一覧はその場でCCFOLIA側を開いて読み込むため、候補が出たらもう一度Enterしてください。切り替えでは一覧のダイアログを一度だけ開いて順に押すので、画面がほとんどちらつきません。

## キャラクターのステータスを変更する

拡張チャットの入力欄にコマンドを入力して送信します。

| 入力 | 動作 |
| --- | --- |
| `1s-10` | 1番のキャラクターのSANを10減らす |
| `2h20` | 2番のキャラクターのHPを20増やす |
| `8m=10` | 8番のキャラクターのMPを10にする |
| `str1` | 能力値ダイス `CCB<={STR}*1 【STR × 1】` を送る |

`h`はHP、`m`はMP、`s`はSANです。`+`で増やし、`-`で減らし、`=`で指定した値にします。

最後の能力値ダイスは `str`・`con`・`pow`・`dex`・`app`・`siz`・`int`・`edu` に数字を組み合わせます（例: `con3` → `CCB<={CON}*3 【CON × 3】`）。数字はCCFOLIA側の能力値参照のかけ算に使われます。

## 更新と詳しい使い方

盤面のキャラクターの並び順を変えたときは、拡張チャットの**更新**を押してください。拡張機能を更新した場合は、拡張機能の管理画面で再読み込みし、CCFOLIAのページも再読み込みします。
