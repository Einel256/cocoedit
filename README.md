# CCFOLIA ステータス変更

> **一般向けの導入・操作ガイドは [GUIDE.md](GUIDE.md) をご覧ください。** この README は仕様・実装の詳細をまとめた開発者向けドキュメントです。

CCFOLIAのルームを操作するChrome拡張機能（Manifest V3）です。拡張機能アイコンから専用の制御ウィンドウを開き、ルームチャットの表示・送信、チャットタブ／発言名／キャラクターの切り替え、技能値パレット、ダイス入力補助、HP・MP・SANのテキストコマンド、メッセージの自動削除を行います。

メッセージ送信やキャラクター切り替えは、CCFOLIA本体の入力欄・送信ボタン・選択メニューを操作して反映します。CCFOLIA側のチャットパネルが閉じていても、ページ内に入力フォームが保持されていれば送信できます。

## 画面構成

制御ウィンドウは上から次の順に並びます。

1. 「設定・キャラクター情報」（折りたたみ式。ヘッダー右の歯車ボタンでも開閉できます）
   - テーマ（Dark / Original）とフォント（デフォルト / JetBrains Mono NF 11pt）の選択
   - メッセージ自動削除（ON/OFF）
   - キャラクター情報の取得と番号割り当て（「一括取得」でキャラ情報・チャットパレット・チャットログをまとめて取得できます）
2. チャットログ
3. チャットタブ（CCFOLIA風のボタン列。タブ名クリックで切り替え、未閲覧タブには赤い「●」の未読バッジ）と「更新」ボタン
4. 発言者行（アイコン、発言名、キャラクター選択、技能値パレットボタン）
5. 技能値パレット（開いたときだけ、ダイス行の上まで広がるオーバーレイで表示）
6. ダイスショートカット（横一列）
7. メッセージ入力欄（入力欄はチャットログと同じ高さまで広がります。技能候補・コマンド候補は入力欄の上に開きます。「クリア」「送信」ボタンは入力欄の上に置きます。入力欄の下に、いま入力対象になっている発言者の名前とアイコンを表示します）
8. 状態表示

制御ウィンドウは10秒ごとにチャット状態の更新を試みます。新しいメッセージは、CCFOLIA側のログが書き変わるたびに即座に反映されます（10秒ポーリングを待ちません）。チャットウィンドウが閉じている間は、取得済みの状態を表示します。自動削除の状態は1秒ごとに更新します。

## 未閲覧タブの新着メッセージ通知

- 自分が見ていないチャットタブに新着メッセージが届くと、制御ウィンドウの状態表示に案内が出て、該当タブのボタン名の右上に赤い「●」の未読バッジが付きます。該当タブに切り替えると消えます。
- あわせて、OSのデスクトップ通知にも「未閲覧のチャットタブに新着メッセージ」と出ます。該当タブを開くと通知も消えます。
- 検知はCCFOLIAタブに表示される新着ドット（タブ名の脇に付く小さな点）で行います。ドットが付いたら新着、タブを開くかドットが消えたら通知を解除します。数字バッジの増分にも対応しているため、タブ名が「メイン0」のように数字を含む環境でも動作します。
- 判定は制御ウィンドウを開いている間の10秒ごとの更新で行います。制御ウィンドウを閉じている間は検知しないため、通知されません。

## 設定・キャラクター情報

### メッセージ自動削除（ON/OFF）

「開始／停止」ではなく、常時有効なモードとして ON／OFF を切り替えます。

- **OFF（初期値）**: 拡張機能はメッセージ画面に一切干渉しません（通常動作）。
- **ON**: 次のサイクルを、メッセージ画面が現れるたびに繰り返します。
  1. メッセージ画面を検出したら、まず全メッセージをスキップします（スキップを押して画面の内容が変わる限り連続で押します）。
  2. 読み切ったら、指定した待ち時間だけ待ちます。待機中に新しいメッセージが届いたら、閉じずに先に全スキップへ戻ります。
  3. 待ち時間経過後、閉じるボタン（`button[aria-label*="閉じる"]` または `svg[data-testid="CloseIcon"]` を含むボタン）でメッセージ画面を閉じます。
  4. 監視に戻り、次のメッセージ画面を待ちます。
- 待ち時間は0.1〜3600秒で指定します。ON/OFFのモードと待ち時間は制御ウィンドウの `localStorage`（キー: `ccfolia-auto-delete-mode-v1`）に保存し、ウィンドウを開き直しても復元されます。
- 読み切った後の画面（閉じるボタンだけのメッセージ画面）は、一度スキップ画面を検出した後に限り閉じます。タブのキャラクター編集画面など、無関係なダイアログの閉じるボタンを誤って押さないための制限です。
- 閉じた判定は最大4回まで再試行し、それでも閉じない場合は Escape キーの送出も試します。クリックは `click()` だけでなく pointerdown/mousedown/pointerup/mouseup も送出します。
- 閉じるボタンがどうしても見つからない場合、その画面の閉じ処理をあきらめて監視に戻ります。
- ONのままルームを再読み込みした場合はモードが解除されるため、制御ウィンドウでONになっているときは復元（自動適用）されます。
- メッセージ画面を見つけられない場合、CCFOLIAページのコンソールに`[CCFOLIA ステータス変更] メッセージ画面を監視中。document上の候補数: …`の診断ログを8回に1回出力します。ボタンが見つからない原因の切り分けに使えます。
- タイマーはCCFOLIAのルームタブ側（Content Script）で動くため、制御ウィンドウを閉じてもONは継続します。止めたい場合は制御ウィンドウを開き直してOFFにしてください。

### キャラクター情報と番号割り当て

「一括取得」ボタンで、キャラ情報の取得・番号割り当てと、チャットパレットの取得、チャットログの更新をまとめて行えます。単独の「キャラ情報を取得」ボタンは廃止しました。

キャラクター一覧の取得は、次の流れで動作します。

1. 盤面上のHP表示行を上から順に取得します。
2. 各行をクリックして編集画面を開き、見出しや名前欄からキャラクター名を読み取ります。
3. 編集画面を閉じ、次のキャラクターへ進みます。
4. 同名のキャラクターがいる場合は、`名前（連番・一覧N番目）` のように区別します。

取得したキャラクターには1〜9の番号を割り当てます。番号は重複できません。割り当ては制御ウィンドウの `localStorage`（キー: `ccfolia-status-characters-v1`）に保存し、番号とキャラクターIDの対応を `chrome.storage.local` の `ccfoliaCommandMap` に同期します。

キャラクターIDは、取得時のHP表示行の並び順（0始まり）です。取得後に盤面の並びが変わると、別のキャラクターに適用される可能性があるため、並びが変わった場合は再取得してください。

チャット用のキャラクター候補（発言名・キャラクター選択プルダウン・ログのアイコン補完・`/c` コマンド）は、別途CCFOLIAのキャラクター選択メニューから取得します。名前、状態、アバター画像URLを読み取り、取得のために開いたメニューは閉じます（選択ボタンを再度押さず、CCFOLIA内の無関係な場所をクリックして閉じるため、メニューが開いたまま残りません）。

## チャット操作

### チャットログ

- ページ内の `ul[aria-label="ルームチャット"][role="log"]` にある `[data-index]` 行を表示します。
- CCFOLIAのログが書き変わるたびに、10秒ポーリングを待たずに即座に制御ウィンドウへ反映します（`CCFOLIA_CHAT_LOG_PUSH` でメッセージ一覧を送出）。チャットウィンドウが閉じていてログが読めないときは、通常の10秒ポーリングで反映します。
- 表示できるのはCCFOLIAの画面上に読み込まれているメッセージです。サーバーから画面外・未読込の過去ログを追加取得する機能はありません。
- 発言者名は `#888`（`#888888` 相当）で表示します。
- メッセージ行には発言者のアイコンを表示します。アイコンは「メッセージ行の画像 → 同じ発言者のログの画像 → 取得済みキャラクター情報の画像」の順に候補を使います。現在選択中の発言者の画像を過去ログへ流用しません。
- 「更新」ボタンで、ログとキャラクター候補を強制的に再取得します。
- CCBなどのロール結果に含まれる `ここから … ここまで` の範囲は、`(1D100<=68) ＞ 57 ＞ 成功` のようなダイス判定の形式を持つ場合に結果を色付けします。成功は `#2089DC`、失敗（ファンブルを含む）は `#D1004A` です。ダイス判定の形式（`(1D100…) ＞`）を持たない範囲は通常の色で表示します。マーカーがない行でも、ダイス判定の出力部分は色付けします。

### チャットタブ

- ログの下のタブボタンでチャットタブを選びます。CCFOLIAと同じ、タブ名が並ぶボタン列で、選択中のタブは赤い下線で示します。下線は選択を切り替えると現在位置からスライドして移動します（タブ列の下に罫線はありません）。
- 制御ウィンドウの入力欄で `/m` と入力すると、チャットタブの候補が入力欄の上に大きく表示されます。文字で絞り込み（スペース区切りで複数語のAND検索）、Tab（下移動）・Shift+Tab（上移動）・↑↓でハイライトを選び、**Enterで候補を反映**します。Tabでは入力欄の内容は書き換えません。Escで閉じます。
- `/c` はキャラクター選択、`/g` は技能選択、`/s` はシーン選択のコマンドです。
- 選択したタブは、制御ウィンドウから送信するときの送信先にも使います。送信前にCCFOLIA側の該当タブをクリックします。

### フォント

- 「設定・キャラクター情報」の「フォント」で、デフォルト（Noto Sans JP など）または **JetBrains Mono NF（11pt）** を選べます。選択は `localStorage`（キー: `ccfolia-font-v1`）に保存され、次回起動時に復元されます。
- JetBrains Mono NF はOSにインストールされたフォントです。環境のインストール名が違う場合（例: 「JetBrainsMono NF」以外の名前）は表示フォントが変わらないことがあります。その場合は `control.css` 末尾の `body[data-font="jetbrains"]` のフォント候補を実際のファミリー名に合わせて調整してください。

### シーン選択（`/s`）

- 制御ウィンドウの入力欄で `/s` と入力すると、シーン名の候補が入力欄の上に大きく表示されます。絞り込み・Tab・Shift+Tab・↑↓・Enter・Escは他のコマンドと共通です。
- 候補を選んでEnterすると、実質的にCCFOLIA本家の「`/scene シーン名`」チャットコマンドを送って、シーンを切り替えます。決定した時点でメッセージ欄はすぐ空になります（送信に失敗した場合のみ元の入力に戻ります）。
- シーン一覧は、シーンパネル（映像アイコンの「シーン」ボタン）のカード一覧を最後までスクロールして読み取ります。取得したものは `localStorage`（キー: `ccfolia-scene-list-v1`）に保存し、以降はパネルを開かずに候補表示できます。
- 「一括取得」でもシーン一覧を取得します。`/s` で候補がひとつもない状態でEnterした場合は、その場でシーンパネルを開いて自動で1回だけ取得し、候補を表示します（自動では切り替えないため、候補が見えたらもう一度Enterしてください）。
- 表示順はシーンパネルの上から順です。同名のシーンが複数ある場合は1つにまとめて表示します。
- 本家の「`/scene シーン名`」コマンドを手入力したい場合はそのまま入れて送信すればOKです（`/scene` から始まる入力はセレクタに奪われません）。
- シーン一覧の取得後は、シーンパネルを「閉じる」ボタンではなく、CCFOLIA内の無関係な場所（ダイアログの外側）をクリックして閉じます。閉じるボタンが効かず一覧がCCFOLIAの画面に残るのを防いでいます。

### 発言名・キャラクター

- 発言名欄からフォーカスを外すと、CCFOLIA側の発言名入力欄へ反映します。
- キャラクター選択プルダウンは発言名欄とは独立しています。キャラクターを選ぶと、CCFOLIA本体のキャラクター選択メニューで該当行をクリックし、発言名もキャラクター名に同期します。
- プルダウンの選択肢はキャラクター名のみを表示します（「選択なし」や状態表記〔アクティブなど〕はありません）。
- 制御ウィンドウの入力欄で `/c` と入力すると、キャラクター候補を入力欄の上に大きく表示して選べます。文字で絞り込み、Tab（下移動）・Shift+Tab（上移動）・↑↓でハイライトを選び、Enterで切り替えます。Tabは入力欄を書き換えないため、検索しながら選択できます。選ぶとCCFOLIA側のキャラクター選択メニューで該当キャラクターに切り替え、発言名も同期し、プルダウンと発言者アイコンも追従します。
- `/c` の候補一覧は、現在の送信者（発言名欄のキャラクター）を常に先頭に表示します。
- 発言者行のアイコンは、CCFOLIA側で現在選択中のキャラクターの画像です。

### 技能値パレット

- 発言者行のリストアイコンを押すと、パレットパネルを開きます。保存済みの一覧を表示するだけなので、CCFOLIA側を操作しません。「再取得」ボタンで全項目を走査し直します。
- パレットパネルは開いている間、ウィンドウサイズにかかわらずダイス行の上まで広がるオーバーレイで表示されます（メッセージ入力欄・ダイスボタンは使えたままです）。「再取得」「閉じる」ボタンはパネルの下側にあります。技能の検索は入力欄の `/g` コマンドで行います。
- 入力欄で `/g` と入力しても、技能候補を同じように選べます。選んだ技能は入力欄に挿入されます（送信はしません）。
- メッセージ入力中に表示される技能候補には、`【ダメージ判定】` の式は出ません（入力の邪魔にならないようにするためです。`/g` コマンドからは選べます）。
- パレットのスクロール領域（`.MuiDialogContent-root.scrollable-list`）を末尾まで走査し、`.MuiListItemButton-root[role="button"] .MuiListItemText-primary` から項目を集めます。実際のスクロール要素は自動検出し、最下部まで段階的にスクロールしてから、項目数・高さ・位置が3回連続で変化しなくなるまで読み込みます。取得後はCCFOLIA側のパレットとルームチャットを閉じます。
- 取得した項目は制御ウィンドウの `localStorage`（キー: `ccfolia-chat-palette-v1`）に保存します。保存済みの項目がある場合、パレットを開いてもCCFOLIA側を再走査せず、保存済みの一覧を表示します。
- 「再取得」ボタンを押したときだけ、CCFOLIA側のダイアログを開いて全項目を走査し直し、保存内容を更新します。
- 拡張ウィンドウには取得した全項目を表示します（`CCB` の技能、`1d100<={SAN}` の正気度ロール、`1d3+0 【ダメージ判定】` などのダイス式を含みます）。
- パレットの項目をクリックすると、メッセージ入力欄のカーソル位置に挿入し、パネルを閉じます。送信はしません。

### ダイスショートカット

- `d2`、`d3`、`d4`、`d6`、`d8`、`d10`、`d12`、`d20`、`d100` と `SAN` の10個のボタンを、横一列にコンパクトに並べています。ダイス個数ボタンは廃止しました。
- ダイスボタンを押すと `1d6` をカーソル位置へ挿入します。続けて同じボタンを押すと、入力済みの式の個数を増やします（`1d6` → `2d6` → `3d6` …へ差し替え）。
- カーソルの直前がダイス式のときは、その連結の中に同じ面数の項があればその個数を増やし、なければ連結の末尾に `+` を付けて合成します（例: d2 → d4 で `1d2+1d4`）。
- 入力内容が変わって差し替え先の式が見つからない場合は、カーソル位置へ新たに挿入します。
- `SAN` は `1d100<={SAN} 【正気度ロール】` を挿入します。
- ダイスボタンで入力欄へ挿入するだけです。送信はしません。
- `CCB<=` 専用のショートカットボタンはありません。

### 送信・クリア

- Enter（Shiftなし、IME変換中を除く）または「送信」で送信します。
- 「送信」を押すと、制御ウィンドウの入力欄はCCFOLIA側の反映を待たずにすぐクリアされます。送信に失敗した場合のみ元の内容を復元します。
- 送信の確定直後からすぐ次の入力・送信を受け付けます（ダイスロールやSANチェックを連続で送るときに、送信できない待ち時間がありません）。チャットログの再取得は送信の後処理として行います。
- 「クリア」は入力欄だけを空にし、送信はしません。
- 制御ウィンドウから送信するときは、CCFOLIAの入力欄へ値を設定し、CCFOLIAの送信ボタン（`button[type="submit"]`）を押します。チャットパネルが閉じていて入力フォームが残っている場合は、そのフォームを直接使います。フォームが残っていない場合はチャットパネルを開いて送信し、閉じます。
- 制御ウィンドウの送信もCCFOLIAの送信ボタンを経由するため、後述のステータスコマンド判定を通ります。

## ステータスコマンド

チャット入力欄（CCFOLIA本体または制御ウィンドウ）にコマンドを入力して送信すると、HP・MP・SANを変更します。

### 書式

```text
<番号><ステータス><演算子><数値>
```

- 番号: 1〜9。複数指定は `1234` のように連続した数字、またはカンマ・空白区切り（例: `1,2`、`1 2`）。重複は1つにまとめます。
- **番号を省略した場合**は、チャットの発言名欄に表示されている「現在の発言者」を対象とします（例: `s-3` で現在の発言者のSANを3減らす）。
- ステータス: `h` / `hp` = HP、`m` / `mp` = MP、`s` / `san` = SAN（大文字小文字は区別しません）。
- 演算子: `+` は増加、`-` は減少、`=` は指定値への設定。符号なしは増加です。
- 旧形式として、ステータス略号と数値の間に空白がある `1s 10` は減少として扱います（`1s10` は増加）。
- 数値は0〜999999の整数です。`0` は `=` 指定時だけ有効です。

### 入力例

| 入力例 | 動作 |
| --- | --- |
| `1s-10` | 1番のSANを10減らす |
| `2h20` | 2番のHPを20増やす |
| `8m=10` | 8番のMPを10にする |
| `1234s-10` | 1〜4番のSANをそれぞれ10減らす |
| `1,2m+5` | 1番と2番のMPをそれぞれ5増やす |
| `1s 10` | 1番のSANを10減らす（旧形式） |
| `s-3` | 現在の発言者のSANを3減らす（番号省略） |
| `h+10` | 現在の発言者のHPを10増やす（番号省略） |
| `m=50` | 現在の発言者のMPを50にする（番号省略） |

### 実行ルール

- 空行を除き、入力全体がコマンド行だけで構成されている場合にコマンドとして実行します。1行でも通常文が混ざっている場合は、入力全体を通常のチャット文として送信します。
- 複数行のコマンドに対応しています。1行に1コマンドを書きます。
- コマンドとして実行する場合、入力欄は送信せずにクリアし、ステータス操作を実行します。
- いずれかの対象（番号、または番号省略時の現在の発言者）が未割り当て／見つからない場合、その入力全体は実行せず、入力欄もクリアしません。エラーはCCFOLIAページのコンソールに出力します。
- 操作対象は盤面上の表示順で処理します。対象のステータス行をクリックして編集画面を開き、増減ボタンを1ポイントずつ押します。
- 増加と指定値設定では、表示中の現在値と最大値を読み、最大値を超えないようにします。指定値が最大値より大きい場合は最大値に制限します。
- 減少と指定値設定では、現在値を0未満にしません。
- HP、MP、SAN以外は操作しません。
- 現在値・最大値を読み取れない場合は、安全のため停止します。
- 各キャラクターの処理後に編集画面を閉じ、反映を待ってから次へ進みます。待ち時間は、編集画面を開いた後40ms、ボタン間5ms、閉じた後300msです。
- 実行済みの変更を拡張機能から取り消す機能はありません。

### resbコマンド（r / rg）

入力全体が次の形式で構成されているとき、CCFOLIA本体・制御ウィンドウのどちらの入力欄からでも、計算結果を `resb<値>` の形でCCFOLIAのチャットへ送信します。**コマンド文そのものは送らず、変換結果の `resb…` だけを送ります。**

```text
r<n>        → resb（n）
r<n> <m>    → resb（n - m）
rg<n>       → resb（n/5 端数切捨て）
rg<n> <m>   → resb（n/5 端数切捨て - m/5 端数切捨て）
```

- `<n>` `<m>` はいずれも自然数（1〜999999）です。
- 区切りはスペース（複数可）・カンマ・**ハイフン**（`r5-3`、`rg10-4`）のどれでも使えます。
- `<m>` を省略した場合は、値そのものを送ります（例: `r5` → `resb5`、`rg5` → `resb1`）。
- 大文字小文字・全角英数字のどちらでも入力できます（例: `R5-3`、`ｒ５　３`）。
- **先頭に `s` を付けるとシークレットダイスになります**。出力は `s` 接頭辞付きの `sresb…` です（例: `sr5 3` → `sresb2`、`srg10 4` → `sresb2`、`srg10-4` → `sresb2`）。
- 複数行に対応します（1行1コマンド）。送信は、値を改行でつないだ1発言になります。通常とシークレットを混在できます（例: `r5 3` と `sr5 3` の2行 → `resb2` と `sresb2`）。
- 結果が `0` や負の値でもそのまま送ります（例: `resb0`、`resb-2`）。
- マッチしない入力（通常の文章、既存のステータスコマンド）はそのままのチャット文として送ります。
- 変換は送信時に行われ、制御ウィンドウの入力欄は通常どおりすぐクリアされます。送信失敗時は元の入力を復元します。
- **チャットログでは、判定結果（成功・スペシャル・決定的成功）は青、（失敗・ファンブル）は赤で色が付きます。`(1d100<=65) ＞ 1 ＞ 決定的成功/スペシャル` のように、ダイス式から判定語までまとめて色が付きます（`resb2` といったコマンド部分だけは通常色のまま、小文字 `d100` 形式のダイス式にも対応）。**

| 入力例 | 送信される内容 |
| --- | --- |
| `r5` | `resb5` |
| `rg5` | `resb1` |
| `r5 3` ／ `r5-3` ／ `r5,3` | `resb2` |
| `r3 5` | `resb-2` |
| `rg10 4` ／ `rg10-4` | `resb2` |
| `rg12 9` | `resb1` |
| `sr5 3` ／ `srg10-4` | `sresb2`（シークレットダイス） |
| `r5 3` + `sr5 3`（2行） | `resb2` と `sresb2`（改行で1発言） |

## セットアップ

1. Chromeで `chrome://extensions` を開きます。
2. 「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます。
4. CCFOLIAのルームを開くか、再読み込みします。
5. 拡張機能アイコンから制御ウィンドウを開き、「一括取得」ボタンで各キャラクターに番号を割り当てます。
6. ルームのチャット入力欄、または制御ウィンドウの入力欄からコマンドを実行します。

## ファイル構成

- `manifest.json`: Manifest V3の設定。`https://ccfolia.com/rooms/*` で `content.js` を読み込みます。権限は `tabs`、`storage`、`notifications`、ホスト権限は `https://ccfolia.com/*` です。
- `background.js`: 拡張機能アイコンから制御ウィンドウを開きます。制御ウィンドウとルームタブのメッセージを中継し、番号割り当てとキャラクター一覧を `chrome.storage.local` に保存します。未閲覧タブの新着メッセージをデスクトップ通知に出します。
- `icon.png`: デスクトップ通知と拡張機能アイコンに使う画像です。
- `content.js`: CCFOLIAページ側の処理。チャット状態の取得、送信、タブ・発言名・キャラクター操作、技能値パレット、メッセージ自動削除、ステータスコマンド、未閲覧タブの新着検知を担当します。
- `control.html`、`control.css`、`control.js`: 制御ウィンドウのUIと操作を担当します。
- `README.md`: 仕様・実装の詳細をまとめた開発者向けドキュメント。
- `GUIDE.md`: 一般向けの導入・操作ガイド。GitHubのトップページから誘導します。

## 実装メモ

### メッセージ中継

`background.js` は次の種類のメッセージを、URLが `https://ccfolia.com/rooms/*` に一致するタブへ転送します。転送先は、読み込みが完了しているタブを優先し、なければ最初の一致タブです。

- `CCFOLIA_ACQUIRE_CHARACTERS`
- `CCFOLIA_CHAT_GET_STATE`
- `CCFOLIA_CHAT_SEND`
- `CCFOLIA_CHAT_SELECT_TAB`
- `CCFOLIA_CHAT_SET_SPEAKER`
- `CCFOLIA_CHAT_SELECT_CHARACTER`
- `CCFOLIA_CHAT_DICE`
- `CCFOLIA_CHAT_PALETTE`
- `CCFOLIA_AUTO_SKIP_MODE`
- `CCFOLIA_AUTO_SKIP_STATUS`

また、`content.js` は `CCFOLIA_CHAT_LOG_PUSH` を、10秒ポーリングを介さずに直接すべての拡張機能コンテキストへ送ります（制御ウィンドウが受けて即時描画します）。`background.js` は転送しません。

制御ウィンドウは `chrome.runtime.sendMessage` で送信し、`content.js` は `*_IN_ROOM` という種類で受け取ります。

### 保存領域

- `localStorage`（制御ウィンドウ）: 自動削除モード（ON/OFFと待ち時間）、取得済みキャラクターと番号、チャットパレットの保存済み一覧。
- `chrome.storage.local`: `ccfoliaCommandMap`（番号 → キャラクターID）と `ccfoliaCharacters`（キャラクター一覧）。ルーム側のContent Scriptがコマンド実行時に参照し、番号省略時の発言者解決に使用します。

### DOM変更時の確認箇所

- チャットログの抽出: `getChatState`。セレクターは `ul[aria-label="ルームチャット"][role="log"] [data-index]`。
- 入力欄と送信: `findChatTextarea`、`sendChatText`、`setReactInputValue`。入力欄は `textarea[name="text"][placeholder="メッセージを入力"]`、送信は `button[type="submit"]`。
- チャットタブ: `clickChatTab`。セレクターは `[role="tablist"] button`。
- 発言名: `setChatSpeaker`。セレクターは `input[name="name"][placeholder="noname"]`。
- キャラクター選択: `getCharacterPickerOptions`、`selectChatCharacter`。起点は `button[aria-label="キャラクター選択"]`（アバター画像があれば `img.MuiAvatar-img` をクリック）です。一覧は `ul.MuiList-root:has(.MuiListItemButton-root[role="button"])` で、各行の `.MuiListItemText-primary`（名前）、`.MuiListItemText-secondary`（状態）、`.MuiListItemAvatar img.MuiAvatar-img`（画像URL）を読み取ります。
- 技能値パレット: `openChatPalette`、`readChatPaletteEntries`。起点は `svg[data-testid="ListAltIcon"]`、一覧は `.MuiDialogContent-root.scrollable-list` 内の `.MuiListItemButton-root[role="button"] .MuiListItemText-primary`。実際のスクロール要素は `scrollHeight - clientHeight` が最大の子孫要素から自動検出します。
- 自動削除: `findSkipDialog`、`findCloseOnlyDialog`、`findMessageDialog`、`dialogSignature`、`runSkipPhase`、`closeCurrentMessage`、`autoSkipTick`、`setAutoSkipMode`、`getAutoSkipStatus`。スキップは `button[aria-label*="スキップ"]`、閉じるは `button[aria-label*="閉じる"]` または `svg[data-testid="CloseIcon"]`。
- キャラクター取得: `getCharacterName`、`acquireCharacters`。
- ステータス操作: `METRICS`、`findMetricRows`、`readCurrentStatus`、`clickOutsideEditor`、`applyToEveryone`。増減ボタンは `button[aria-label="HPを増やす"]` などの `aria-label` で探します。
- コマンド解析: `parseChatCommands`、`parseResCommandLines`、`makeResCommandText`、`interceptChatCommand`、`executeChatCommand`、`executeResCommand`。

## 注意・既知の制約

- CCFOLIAのDOM構造やアクセシビリティラベルが変わると動作しなくなります。表示行やボタンが見つからない場合は、安全のため停止します。
- 実行済みの変更を拡張機能から取り消す機能はありません。実行前にコマンドを確認してください。
- チャットログは画面上に読み込まれている行だけを表示します。サーバーから過去ログを追加取得しません。
- 番号割り当ては取得時のHP表示行の並び順に紐づきます。盤面の並びが変わった場合は再取得してください。
- ステータス変更は1ポイントずつ増減ボタンを押すため、大きな値の変更には時間がかかります。
- コマンド実行時のエラーはCCFOLIAページのコンソールに出力され、制御ウィンドウの状態欄には表示されません。
- 複数のCCFOLIAルームタブを開いている場合、操作対象は読み込みが完了している最初の一致タブです。
- CCFOLIAの実ルームでの最新変更の動作確認は未実施です。
