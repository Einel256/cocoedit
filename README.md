# CCFOLIA 全員HP減少

拡張機能アイコンから専用の制御ウィンドウを開きます。各キャラクターのHP表示行をクリックし、`aria-label="HPを減らす"` のボタンを指定回数押します。HP以外のステータスは操作しません。

## 読み込み

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. CCFOLIAのルームを開く、または再読み込みする
5. Chrome右上の拡張機能アイコンから本拡張機能をクリックし、専用ウィンドウで実行する

## 注意

- CCFOLIAのDOM変更で動かなくなる可能性があります。その場合は `content.js` 冒頭の `SELECTORS` を調整してください。
- HPラベルを確認できない場合は安全のため何も送信しません。
- 実行前に対象と減少値を確認してください。送信済みコマンドをこの拡張機能から取り消す機能はありません。
- 非公式の拡張機能です。CCFOLIAの利用規約・卓の合意に従って使用してください。
