# CCFOLIA ステータス変更

Chrome拡張機能アイコンから制御ウィンドウを開き、CCFOLIAルームのチャットを表示・操作できます。メッセージはCCFOLIA本体の入力欄と送信ボタンを通じて送るため、ルームのチャットに反映されます。チャットタブ、発言名、キャラクター、ダイスショートカットを操作できます。キャラクターを選ぶと、発言名もキャラクター名に切り替わります。キャラクター番号を1〜9で割り当てると、チャット入力からステータスコマンドも使えます。

「自動スキップ間隔（秒）」を指定して開始すると、表示中のメッセージ画面で指定秒数ごとに「スキップ」を押します。スキップボタンがなくなるか無効になった時点で、その画面の「閉じる」を押して終了します。途中で止める場合は「停止」を押してください。自動処理はルームタブ上で動くため、制御ウィンドウを閉じても継続します。

CCFOLIA側でチャットパネルを閉じていても、拡張機能から送信できます。キャラクター候補は、CCFOLIAのキャラクター選択アイコンを押して表示されるメニューから取得します。チャットログはCCFOLIAの画面上で取得できる全メッセージを表示します。

## コマンド

チャット入力欄に1行1コマンドで入力します。番号は1〜9を使い、複数キャラクターは番号を続けて書くか、カンマまたは空白で区切ります。

| 入力例 | 動作 |
| --- | --- |
| `1s-10` | 1番のSANを10減らす |
| `2h20` | 2番のHPを20増やす |
| `8m=10` | 8番のMPを10にする |
| `1234s-10` | 1〜4番のSANをそれぞれ10減らす |
| `1,2m+5` | 1番と2番のMPをそれぞれ5増やす |

`h`はHP、`m`はMP、`s`はSANです。数値の前に`+`を付けると増加、`-`を付けると減少、`=`を付けると指定値への設定になります。符号を省略した数値は増加です。従来形式の`1s 10`（ステータス略号と数値の間に空白）は減少として扱います。

コマンド行だけの入力はEnterまたは送信ボタンで実行し、通常のチャット文はそのまま送信します。複数行のコマンドにも対応します。番号割り当てを変更した場合、拡張機能が設定をルームと同期します。拡張ウィンドウの送信欄も同じ処理を使い、通常文はCCFOLIAのチャットに送信し、ステータスコマンドはステータス操作として実行します。

## 変更ルール

- HP、MP、SAN以外は操作しません。
- 増加と指定値設定では、表示されている現在値・最大値を読み、最大値を超えないようにします。指定値が最大値より大きい場合は最大値に制限します。
- 減少と指定値設定では、現在値を0未満にしません。
- 各キャラクターの処理後に編集画面を閉じ、変更の反映を待ってから次へ進みます。

## 読み込み

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. CCFOLIAのルームを開く、または再読み込みする
5. 拡張機能アイコンから制御ウィンドウを開き、「キャラ情報を取得」を押して各キャラクターに番号を割り当てる
6. ルームのチャット入力欄でテキストコマンドを実行する

## 注意

- CCFOLIAのDOM変更で動かなくなる可能性があります。表示行やボタンが見つからない場合は安全のため停止します。
- 実行済みの変更を拡張機能から取り消す機能はありません。実行前にコマンドを確認してください。
